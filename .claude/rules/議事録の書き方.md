# 議事録の書き方

議事録は決まったことのリスト（結果集）ではない。原本（書き起こし）を見なくても、どんなやりとりがあり、誰が何を懸念・提案し、どう返し、なぜその結論になったかまで追えるように書く。

## 基本方針

- なるべく要約しすぎない。一行に圧縮して誰の発言か・何に対する反応かが消える書き方は避ける
- 何をすべきか（アクション・担当）は明確にしつつ、どんな会話の末にそうなったかが読める分量と構造にする
- 決まったこと・やることだけで終わらせず、会話の流れ・議論の背景・考え方・マインドセット・こうあるべき論・ノウハウを同じ文書に含める
- 見出しは「日付＋箇条書きだけ」にせず、話題の山ごとに小見出し（`###`）を立てる

## 含めるべき要素

| 要素 | 内容 | 例 |
|------|------|-----|
| 議論の流れ・背景 | 何が課題で、誰が何を言い出し、どう広がったか | 「Aさんイベントが本当に初心者向けかBさんが不安」 |
| やりとりの痕跡 | 単発の結論だけでなく、誰がどう応じたか | 「A: すみませんでした」「C: 自分でやる方がよいとの整理で着地」 |
| 考え方・マインドセット | 共有された価値観・前提 | 「共犯者・シチュエーショントリガー」 |
| こうあるべき論 | そもそも論・あるべき姿 | 「告知は主催・参加者も『行く』と出す」 |
| ノウハウ・気づき | 具体的な知見・打ち手 | 「チェックリストをフォームで『目を通したか』確認」 |
| 決まったこと | 結論・決定事項 | 役割分担、廃止・開始の合意 |
| やること | アクション・担当 | チェックボックス＋担当者名で Who が分かる形 |
| 検討中・方針 | 継続議論するテーマ | 具体案が出たが未決のもの |

## 情報量の目安

- 決まったことだけ、またはそれに近い薄い箇条書き → 不十分。やりとりが再現できない
- 決まったことの分量のおおよそ3〜5倍以上を、議論の流れ・やりとり・考え方・ノウハウに割く
- 「ミーティングの要約」という言葉に引きずられて過度に短くしない
- 要約 = 情報の削ぎ落としではなく、読みやすい形への再配置
