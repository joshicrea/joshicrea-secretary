# ファイル・フォルダ命名規則

新規作成・リネーム時に守る3つのルール。既存ファイルは触る時点で修正する（一括変更は不要）。

## 1. 日本語で作成する

- 新規作成するファイル・フォルダの名前は基本的に日本語で付ける
- 同じフォルダ内も日本語に揃える

例外（英数字のままでよい）:
- 拡張子（`.md` `.py` 等）
- 日付（`20260206` 等）
- 技術的に必要な英数字（コード・ツール・HTML）
- サービス名・製品名（YouTube・Instagram・LINE・Meta・Facebook 等。カタカナ化しない）
- 人名の固有名詞

英語名になりやすい注意点:
- 他プロジェクトからのコピー
- AI・ツールが英語名でデフォルト作成
- 「特定フォルダは対象外」と誤解（同じフォルダ内も日本語に揃える）

## 2. 80文字以内に収める

Gitの `Merge with strategy ort failed` 等のエラーを防ぐため、ファイル名・フォルダ名は80文字以内とする。

- 80文字を超える場合は意味が分かる範囲で短くする
- 新規作成・リネーム時に必ず80文字以内
- 既存で80文字超のものは、Gitに格納する際（触る時点）に短くする

## 3. Windows禁止文字を使わない

Macでは使えるがWindowsで使えない文字をファイル名・フォルダ名に含めない。共有リポジトリではWindowsでも動くことを前提にする。

| 禁止文字 | 説明 | 代替例 |
|---------|------|--------|
| `\ /` | パス区切り | 使わない |
| `:` `：` | コロン（半角・全角両方禁止） | `-` `_` で置き換え |
| `*` `?` | ワイルドカード | 使わない |
| `"` `<` `>` | リダイレクト・引用 | 使わない |
| `\|` | パイプ | `_` で置き換え |
| `#` | アンカー | 使わない |

時刻表記: `7:00` `7：00` ではなく `7-00` `0700` で表記する。
