# 使用ツール設定

このファイルはセットアップ時に自動で更新されます。
設定内容は `{{SECRETARY_BASE_DIR}}/ユーザープロフィール.md` に記録されています。

## ツール別の動作ルール

### メルマガ配信ツール

ユーザープロフィール.md に記載されたツールに合わせて出力形式を調整する。

- **UTAGE**: プレーンテキスト形式。HTML不使用。改行で段落を区切る
- **Mailchimp**: HTML対応。リンクはボタン形式を推奨
- **MyASP**: プレーンテキスト形式。件名は20文字以内推奨
- **その他**: プレーンテキスト形式をデフォルトとする

#### 配信前バリデーション（外部サービスへの投稿前に必ずチェック・例外なし）

外部メルマガツール（UTAGE / MyASP / Mailchimp 等）の「下書き作成」「送信」APIを呼ぶ前に、以下を自分でチェックする。1つでも該当したら送信しない。修正してからAPIを呼ぶ。

| 検出パターン | 対処 |
|---|---|
| `[`〜`]`・`{`〜`}` の角括弧/波括弧プレースホルダーが残っている | 配信用本文に残さない。URLが未確定なら該当段落ごと削除する |
| 本文1行目が件名と同一・類似 | 重複を削除。1行目は挨拶から開始する |
| 署名ブロックがない | 末尾に署名を追加する |
| 「[ここに〇〇を差し込み]」等の人間補完前提テキスト | 確定テキストを差し込むか、段落ごと削除する |
| 絵文字が含まれている | 全削除する |

### ブログ投稿先

ユーザープロフィール.md に記載されたブログ媒体に合わせて出力形式を調整する。

- **Ameblo**: スマホ読みやすい短い段落。装飾（太字・下線）を適度に使う
- **note**: Markdown対応。見出し・引用・区切り線を活用する
- **WordPress**: HTML対応。SEOを意識した構成（H2・H3の階層）

### SNS投稿形式

- **Instagram**: ハッシュタグ20-30個。改行多め。絵文字は使用しない
- **X（旧Twitter）**: 140文字以内。スレッド形式も可
- **YouTube**: タイトル30文字以内。説明文にタイムスタンプ入り

### Google Calendar 連携

`mcp__claude_ai_Google_Calendar__list_events` を使用する。
連携設定は Claude Code の MCP 設定画面で行う。

### Gmail 連携

`mcp__claude_ai_Gmail__search_threads` を使用する。
連携設定は Claude Code の MCP 設定画面で行う。
