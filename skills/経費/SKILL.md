# 経費メモスキル

## ミッション

「今日〇〇円使った」だけで記録して、月末に集計できるようにする。

---

## 「〇〇円使った」「〇〇円（内容）を経費に入れて」

`{{SECRETARY_BASE_DIR}}/memory/経費/YYYY-MM.md` に追記する（今月のファイルに追記）。

記録フォーマット:
```
- YYYY-MM-DD: 〇〇円 / 〇〇（内容）
```

内容が言われていない場合: AskUserQuestion で「何の費用ですか？（例: 交通費・ランチ・ツール代）」と確認する。

記録後: 「〇〇円（〇〇）を記録しました。今月の合計: 〇〇円」と報告する。

---

## 「今月の経費」「経費いくら使った？」

`{{SECRETARY_BASE_DIR}}/memory/経費/YYYY-MM.md` を読んで集計して表示する:

```
【〇月の経費】合計: 〇〇円

内訳:
- 〇〇: 〇〇円
- 〇〇: 〇〇円

明細:
- 〇月〇日: 〇〇円（〇〇）
```
---

## 「領収書処理して」「経費フォルダ見て」「領収書のメモ」

`{{SECRETARY_BASE_DIR}}/領収書/`（未処理置き場）にアップロードされた領収書画像を、まとめて読み取って経費メモに変換する。

### 手順

1. `{{SECRETARY_BASE_DIR}}/領収書/` 直下（`済/` は除く）にある画像ファイル（jpg/jpeg/png/heic/pdf）を列挙する
2. 対象が0件なら「未処理の領収書はありません」と伝えて終了する
2-B. heic（iPhoneの標準の写真形式）はそのままでは読み取れない。読む前にJPEGへ変換し、変換後の画像を読む。変換後のJPEGは一時フォルダに作り、`領収書/` には残さない
   - Mac: `sips -s format jpeg "<元.heic>" --out "<一時フォルダ>/<元の名前>.jpg"`
   - Windows: `py -c "import pillow_heif,sys;pillow_heif.register_heif_opener();from PIL import Image;Image.open(sys.argv[1]).convert('RGB').save(sys.argv[2])" "<元.heic>" "<一時フォルダ>/<元の名前>.jpg"`。`pillow_heif` が無いと出たら `py -m pip install --user pillow-heif` を実行してからもう一度変換する
   - それでも変換できなければ、その1件を保留にし、理由に「写真の形式（HEIC）を変換できませんでした。iPhoneの 設定 → カメラ → フォーマット を「互換性優先」にして撮り直すと読み取れます」と書く。heic を変換せずに読んで金額を推測することはしない
3. 各画像を読み取り、次の4項目を抽出する: 日付・金額・店舗名（支払先）・大分類
   - 大分類は次の候補から1つ選ぶ: 交通費・消耗品費・接待交際費・会議費・通信費・地代家賃・水道光熱費・雑費
   - 判読できない項目（日付不明・金額不明瞭・複数金額の候補がある等）は、その画像だけ保留にして一覧の最後にまとめる
   - 小計・消費税・合計・お預り・お釣りが並ぶレシートは「合計」（無ければ「ご請求額」「お会計」）の金額を使う
3-B. 追記する前に、その月の経費ファイルに同じ日付・同じ金額・同じ支払先の行が既にないか見る。あれば二重に記録しないよう、その画像は保留にし、理由に「同じ内容の記録が既にあります（撮り直し・二重アップロードの可能性）」と書く
4. 読み取れた分は `{{SECRETARY_BASE_DIR}}/memory/経費/YYYY-MM.md`（日付基準の月）に追記する。フォーマット:
   ```
   - YYYY-MM-DD: 〇〇円 / 〇〇（内容） / 領収書: 元ファイル名
   ```
5. 追記が終わった画像だけを `{{SECRETARY_BASE_DIR}}/領収書/済/YYYY-MM/大分類/`（日付基準の年月・その画像の大分類のフォルダ）へ移動する（保留分は未処理のまま残す）。フォルダが無ければ自動作成する。同じ名前のファイルが既にあるときは上書きせず、`IMG_0101_2.jpg` のように末尾に番号を付けて移動し、経費メモの「領収書:」も新しい名前に合わせる（iPhoneのファイル名は機種変更や1万枚ごとに同じ番号が繰り返されるため、上書きすると以前の領収書が消える）
6. 結果をまとめて報告する:
   ```
   領収書3件を記録しました（合計8,400円）。
   - 09-15: 1,200円 / タクシー（交通費）
   - 09-20: 3,600円 / 文房具店（消耗品費）
   - 09-22: 3,600円 / カフェ（接待交際費）

   保留1件（金額が不鮮明で読み取れませんでした）: IMG_0231.jpg
   ```

### 判断に迷う場合

大分類の判断が微妙なとき（交際費か会議費か等）は、そのつど確認せず妥当な方を選んで記録し、報告の中で「〇〇として記録しました（違えば直します）」と一言添える。金額・日付など数値そのものが不鮮明なときだけ保留にする。

### 保留分の扱い

「保留の領収書を見せて」と言われたら、`{{SECRETARY_BASE_DIR}}/領収書/` 直下に残っている画像のファイル名と、読み取れなかった理由を一覧で示す。手入力で追記したい場合は通常の「〇〇円使った」の言い方で記録できる。

## 完了後のプロアクティブ提案

経費を記録したとき（以下の条件に当てはまる1行だけ添える）:
- 初めて経費を記録したとき: 「「〇〇の支払い毎月〇日」と言うと毎月の固定費を自動管理できます。」
- 今月の経費が先月より増えている場合: 「「今月の経費」で詳細を確認できます。」

提案は1回につき1つだけ。押しつけない。

## エラーフォールバック

### MCP未接続時
- このスキルはファイル操作のみのため、MCP接続状況の影響なし

### ファイル不在時
- `{{SECRETARY_BASE_DIR}}/memory/経費/` が存在しない場合は自動作成してから処理を続ける
- 今月の経費ファイル（`YYYY-MM.md`）が存在しない場合は自動作成してから追記する
- `{{SECRETARY_BASE_DIR}}/領収書/` および `{{SECRETARY_BASE_DIR}}/領収書/済/YYYY-MM/大分類/` が存在しない場合は自動作成してから処理を続ける
- 書き込み権限エラー時: まず対象パスが存在するか・別のアプリ（同期中など）が掴んでいないかを確かめて1回だけ再試行する。それでも失敗したら「経費フォルダへの書き込みができません。Claude Codeを再起動してから試してください」と案内する

### 領収書画像が読み取れない場合
- 画像が破損・空・非対応形式（jpg/jpeg/png/heic/pdf以外）の場合はその1件を保留に回し、他の画像の処理は続ける
- 手ブレ・逆光等で日付や金額の一部だけ読めない場合も保留に回し、読めなかった項目を理由として示す

### ツール実行エラー時
- dateコマンドが失敗した場合: ユーザーに「今日の日付を教えてください（例: 2026-05-18）」と確認してから記録する
- ファイル読み込みエラー時: まずファイルが存在するかを確かめて1回だけ再試行する。それでも失敗したら「経費ファイルの読み込みに失敗しました。Claude Codeを再起動してから試してください」と日本語で案内する
- エラーは日本語で要約して伝え、末尾に `原文: ...` としてエラーの原文を1行添える

---

## 禁止事項

- 実際にファイルを読まずに合計を言う
- 今日の日付をハードコードする
- 絵文字の使用
- 領収書画像を実際に読まずに金額・店舗名を記録する
- 読み取れなかった項目を推測で埋めて記録する（保留に回す）
- `済/YYYY-MM/大分類/` の既存ファイルを上書きする
- heic を変換せずに読み、中身を推測して記録する
